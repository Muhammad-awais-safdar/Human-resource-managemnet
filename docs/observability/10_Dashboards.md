# 10 - Dashboard Catalog & Panel Specifications

## Dashboard Catalog
1. **01 - Infrastructure & Docker Overview**: CPU, Memory, Disk, Container CPU via cAdvisor.
2. **02 - JVM & Spring Boot Metrics**: Heap memory, GC pause duration, Threads live vs daemon, Metaspace.
3. **03 - PostgreSQL Database Overview**: Active connections, Transactions/sec, Cache hit ratio, Hikari pool.
4. **04 - Redis Cache Performance**: Memory usage, Commands/sec, Cache hit ratio %, Connected clients.
5. **05 - API Requests, Latency & Error Rate**: Request throughput (req/s), Latency P50/P95/P99, HTTP 5xx error rate %.
6. **06 - Executive Business KPIs & Financial Metrics**: MRR, ARR, Active Tenants, Employee count, Attendance activity, Payroll failures.
7. **07 - Multi-Tenant Operations & Resource Usage**: Per-tenant request traffic, error rate, active users, storage usage.
8. **08 - Developer Deep-Dive & Tracing Diagnostics**: Connection acquire times, Query duration, Tracing latencies, Slow request counts.
