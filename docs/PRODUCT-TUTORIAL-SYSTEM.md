# Product Tutorial & Help Center System Documentation

## Overview

The Interactive Tutorial & Help System provides self-service onboarding, searchable knowledge guides, contextual popover explanations, and release changelogs.

---

## Core Components

1. **`HelpCenterModal.jsx`**: In-app modal accessible via the header or sidebar, offering category search and "Learn How" interactive tour launchers.
2. **`WhatsNewModal.jsx`**: Release changelog modal displaying new features, enhancements, and bug fixes.
3. **`ContextualHelpPopover.jsx`**: Inline `?` triggers for complex enterprise concepts (e.g. Maker-Checker approvals, piece-rate calculations, biometric device sync).
